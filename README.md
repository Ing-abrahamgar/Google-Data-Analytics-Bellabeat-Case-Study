## 🔍 Descripción del Proyecto

Este proyecto aborda la preparación, transformación y análisis de datos estructurados para identificar patrones, tendencias y correlaciones importantes. 

**Objetivos principales:**
1. Sanitizar y estructurar conjuntos de datos con valores faltantes o inconsistencias.
2. Realizar un **Análisis Exploratorio de Datos (EDA)** detallado mediante estadísticas descriptivas y visualización de datos.
3. Extraer métricas de valor que faciliten la toma de decisiones basada en evidencia técnica.
